# OneCal(カレンダー統合管理アプリ)

## 概要

このアプリでは日々の予定管理と家計管理を
カレンダーを軸に統合しました。
情報の分散を防ぎ、日付単位での振り返りを可能にしました。

## 主な機能

-ログイン・ログアウト機能 -ユーザ一覧・編集・削除機能 -カレンダー画面 -当日詳細機能 -予定新規登録、追加、削除機能 -収支新規登録、追加、削除機能

## 開発環境

PHP 8.2.12
MySQL 10.4.32
Laravel 10.50.0
