# OneCal(カレンダー統合管理アプリ)

## 概要
このアプリでは日々の予定管理と家計管理を
カレンダーを軸に統合しました。
情報の分散を防ぎ、日付単位での振り返りを可能にしました。

## 主な機能
- ログイン・ログアウト機能  
- ユーザ一覧・編集・削除機能  
- カレンダー画面表示  
- 当日詳細表示機能  
- 予定／タスク新規登録・編集・削除機能  
  - 終日設定対応  
  - 繰り返し登録機能  
  - 一括編集・一括削除機能  
- 収支新規登録・編集・削除機能  
  - 繰り返し登録機能  
  - 一括編集・一括削除機能  

## 工夫した点
- 繰り返し登録機能の一括編集／一括削除ロジックを実装
- 終日・時間指定の分岐処理をControllerで統一
- 過去日＋時刻編集時の不具合を修正
- 条件分岐の漏れによる表示・更新処理の破綻を修正
